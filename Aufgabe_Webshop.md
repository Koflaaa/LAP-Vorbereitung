# Aufgabe: Webshop

Um dem allgemeinen Trend zum Onlinehandel zu folgen, möchte unser Kunde schrittweise eine Website mit einem Online-Shop aufbauen. Damit soll der Kundenkreis erweitert werden und Neukunden gewonnen werden. Durch die Erweiterung der Präsentation sollen die regionalen Beschränkungen des Geschäfts der Vergangenheit angehören.

1. Entwerfen Sie das Datenbank Design als ER-Diagramm und führen Sie eine Zeitschätzung zur Ausarbeitung des Projekts durch. Setzen Sie die Lösung in einer objektorientierten Programmiersprache um.
2. Erstellen Sie eine Auflistung der gesamten Produktauswahl.
   a. In der Liste soll die Produktbezeichnung, der Preis und ein Bild von jedem Produkt angezeigt werden. Es können aber auch mehrere Produkteigenschaften angezeigt werden.
   b. Der Anwender soll ein Produkt aus der Liste auswählen können, von dem dann alle Eigenschaften angezeigt werden.
   c. Die Produkte und deren Eigenschaften werden in der Datenbank gespeichert. Bilder können am Dateisystem, der Pfad aber in der Datenbank gespeichert werden.
3. Die Produkte sollen über die Website bestellt werden können, dazu setzen Sie um:
   a. Einen Warenkorb
   b. Die Daten des Kunden für die Zustellung
      i. Rechnungsadresse / Lieferadresse
      ii. E-Mail-Adresse, Telefonnummer
   c. Bezahlung per Rechnung oder Kreditkarte. Nur die Auswahl muss umgesetzt werden.
4. Der Webshop soll auf unterschiedlichen Geräten verwendbar sein.
5. Implementieren Sie eine logische und ansprechende Benutzeroberfläche für diese Anforderungen.
6. Erstellen Sie auf einer eigenen Seite eine Statistik über
   a. die fünf am seltensten bestellten Produkte
   b. die meistbestellten fünf Produkte
   c. alle Bestellungen der letzten vier Wochen
7. Erstellen Sie eine Anforderungsliste, die von der Hostingumgebung erfüllt werden muss, um die Funktion und Sicherheit Ihrer Seite zu gewährleisten.

## Zusatzaufgaben:

a. Erstellen Sie die Produktdetailseite so, dass neue Produkte angelegt, bestehende editiert oder gelöscht werden können.
b. Bieten Sie dem Benutzer an, ein Kundenkonto zu erstellen, um beim nächsten Mal nicht alle Daten wieder ausfüllen zu müssen. Implementieren Sie diese Aufgabe.
c. Erstellen Sie aus den Angaben eine Rechnung, die dem Kunden angezeigt wird (HTML Format).

## Hinweise:

- Achten Sie auf die Usability Ihres Webshops
- Dokumentieren Sie die durchgeführten Arbeiten, kommentieren und strukturieren Sie Ihren Code.
- Befüllen Sie die Datenbank mit mindestens 20 Produkten, 5 Kunden und 10 Bestellungen
- Ein ansprechendes Layout erhöht die Verkaufschancen Ihres Shops
